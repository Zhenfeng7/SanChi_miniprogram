# 三尺美术馆微信小程序（首版）

四个导航页：主页、预约、商城、我的。主页展示轮播占位画面、当前/过往展览与联系信息；预约页按展览选择日期、人数和 1 小时时段；“我的”提供个人信息与预约记录。商城暂显示筹备中。

项目使用微信云开发。**代码提交后还需在微信开发者工具中部署云函数、创建集合并填写展览内容，才能进行真实预约。**当前没有收到云环境 ID 或正式展览资料，因此不预置虚构展览，也不在客户端缓存预约名额。

## 开始使用

1. 用微信开发者工具打开项目根目录，确认 AppID 与实际小程序一致，开通云开发环境。
2. 在 `miniprogram/app.js` 的 `wx.cloud.init` 中填写实际环境 ID：`wx.cloud.init({ env: '你的环境ID', traceUser: true })`。
3. 在云开发控制台的数据库创建 `exhibitions`、`settings`、`users`、`bookings`、`slots`、`bookingGuards` 六个集合。**客户端权限设为不可读写**；所有访问通过 `gallery` 云函数。云函数拥有服务端数据库权限。
4. 右键 `cloudfunctions/gallery`，选择“上传并部署：云端安装依赖”。
5. 按 [云端内容与管理说明](docs/cloud-admin.md) 填写 `settings/main` 和展览记录，随后在开发者工具预览。

## 预约规则

- 展览只有在 `startDate` 至 `endDate` 的范围内可预约；过往展览仅供浏览。
- 时段为 1 小时，按各时段 `capacity` 限制人数。确认预约和取消预约在云数据库事务中同步更新占用名额。
- 姓名和手机号必填；一次最多 4 人；同一用户、同一展览、同一天只可有一条有效预约。
- 至少提前 `advanceDays` 天，默认 1 天；一次最多 `maxPeople` 人，默认 4 人。管理员在 `settings/main` 修改。
- 微信云身份自动识别用户，重新打开小程序无需再次登录。用户可输入手机号，或通过微信手机号快捷授权填入。

## 首版范围

“我的订单”、购物车、收货地址未展示，商城尚未接入交易。馆内照片、联系方式、展览资料可由管理员后续补充。云开发控制台能查看预约与取消状态；管理员直接修改预约记录时，须同时维护 `slots` 和 `bookingGuards`，具体见管理说明。
