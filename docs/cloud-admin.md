# 馆方管理使用说明

馆方用自己的微信打开小程序，在「我的 → 馆方管理」维护展览、预约和首页内容。管理员不需要逐条编辑数据库字段。首位管理员或已获得“账号管理”权限的管理员可在小程序中管理其他管理员。

## 首次启用（只做一次）

1. 在微信开发者工具的云开发控制台确认环境为 `cloud1-d1gdj95dne76b8cf6`，部署最新版 `gallery` 云函数。
2. 确认已有 `exhibitions`、`settings`、`users`、`bookings`、`slots`、`bookingGuards` 六个集合，且**客户端权限都设为不可读写**。小程序所有数据库访问都通过云函数。
3. 指定的馆方微信先打开小程序，进入「我的信息」，保存昵称。云开发控制台打开 `users` 集合，找到刚保存的记录，复制该记录的 `_id`（微信 OpenID）。
4. 在 `settings` 集合打开 `_id` 为 `main` 的馆方设置记录，新增字符串字段 `adminOwnerOpenid`，值粘贴上一步的 OpenID；再新增数组字段 `adminOpenids`，第一项填同一个 OpenID。保存后，馆方微信重新进入「我的」即可看到「馆方管理」。账号管理授权会由小程序维护在 `adminManagerOpenids` 字段中。管理员相关字段只由后台读取，不会通过公开的设置接口返回。**不要把管理员 OpenID 写进小程序代码。**旧版的 `adminOpenid` 字段仍兼容。
5. 云存储的安全规则须允许管理员 OpenID 上传图片，图片读取向访客开放。按云开发控制台当前规则格式配置，例如：

```json
{
  "read": true,
  "write": "auth != null && auth.openid == '把这里换成管理员的OpenID'"
}
```

第 5 步是为了防止普通访客上传文件。**新增管理员后，开发者还需把其 OpenID 加入云存储写入规则，否则该管理员可以管理文字内容和预约，但不能上传图片。**更改规则前，请确认云存储里没有其他需要写入的业务；图片上传后会占用云存储空间。

## 日常操作

- **展览**：馆方管理首页点「新建展览」或已有展览，填写名称、介绍、起止日期，上传封面和详情图片，设置每天预约的开始时间、结束时间及每时段总人数。每档为 1 小时；默认 10:00—17:00，即最后一档为 16:00—17:00，每档 12 人。旧展览若原来使用不连续时段，修改这三个设置后会改为连续时段。最后打开「发布展览」并保存。关闭时是仅馆方可见的草稿；开启后访客可看见，日期和时段符合规则时可预约。展览过期后自动归入「过往展览」，访客只能查看详情。已有有效预约的日期或时段不能删除，时段上限也不能低于已占人数；若要隐藏展览，请关闭「发布展览」。仅无有效预约的展览可删除。
- **预约**：点「预约管理」先看今天的有效预约；之后的预约默认收起，点标题可展开。「显示全部」会展开之后的预约，并显示过去 7 天的记录及已取消记录。点「代客预约」填写姓名、手机号、展览、日期、时间和人数；点有效记录可修改或取消。取消会同时释放名额、更新重复预约限制，并在访客的「我的预约」同步显示已取消。代客预约没有绑定访客微信账号，因此不会出现在该访客的「我的预约」中，请由馆方直接通知客人。
- **馆方资料**：点「馆方资料与首页轮播」，修改电话、地址、开放时间、至少提前几天预约、每次最多人数。轮播照片可以添加、上移、下移或移除；保存后访客刷新首页即可看到。轮播列表为空时继续显示小程序自带照片。
- **管理员账号**：首位管理员和已获“账号管理”权限的人可看到。新馆方人员先用自己的微信打开小程序，在「我的信息」授权手机号；账号管理员在「管理员账号」输入该手机号，核对昵称后添加。添加后可单独授予“账号管理”权限；被授权者也可继续授权其他管理员。收回该权限不会移除普通馆方管理权限；移除管理员会同时收回两种权限。不能修改自己的账号管理权限，也不能移除首位管理员。

## 规则与注意事项

- 日期使用北京时间，格式为 `YYYY-MM-DD`。开始日与结束日均可预约；最早预约日按馆方设置计算，默认至少提前 1 天。
- 每个时段为 1 小时。每次预约 1 至馆方设置的最多人数，默认最多 4 人。时段满额后不能继续预约。
- 同一展览、同一天、同一个微信账号或手机号只能有一条有效预约。访客手机号由微信授权，馆方代约手机号由馆方填写，请在现场核实。
- 预约修改、取消、新增都由云函数在数据库事务中更新 `bookings`、`slots` 和 `bookingGuards`。**不要直接在数据库里改预约记录**，否则人数统计会失准。
- 旧版已存在的有效预约不一定有手机号防重记录；云函数会在新建预约时查询旧记录以阻止同手机号重复预约。若过去允许同一手机号使用不同格式录入，需要馆方人工核对旧记录。
